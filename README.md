# Excel Exercises

A collection of practical Excel exercises focused on data cleaning, analysis,
and reporting — completed as part of hands-on data analyst training.

Each folder is a self-contained exercise with its own README, raw dataset, and
cleaned/final output.

## Exercises

| Folder | Topic | Skills covered |
|---|---|---|
| [Data_Cleaning](./Data_Cleaning) | Cleaning messy raw data (Singapore schools dataset) | TRIM, COUNTIF, COUNTIFS, DATEVALUE, PROPER, Flash Fill, Go To Special, duplicate removal |
| [LOOKUP](./LOOKUP) | Lookup and reference functions | VLOOKUP, INDEX/MATCH |

## Skills demonstrated across this repo

- Data cleaning: removing blanks and duplicates, trimming text, standardizing
  dates and casing
- Formulas: COUNTIF/COUNTIFS, VLOOKUP, INDEX/MATCH, TRIM, PROPER, DATEVALUE
- Data validation and text-to-columns / Flash Fill techniques
- Structuring raw data for analysis and reporting
